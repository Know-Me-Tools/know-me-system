Walkthrough

Flow map

Every view and state reachable from this console, grouped by journey. Open any node to land directly in that state — including the dialogs and empty states that normally need an action to trigger them.

Built — implemented and interactive Partial — visible but not fully wired Not built — named here, absent from the prototype

How to use this

Every node links to the exact state it describes. States that normally require an action — a dialog, a filtered table with no matches — have their own routes here, so you never have to reproduce the condition by hand.

Once you leave the map, a Flow map control stays pinned at the bottom-left of every view so you can step back without using browser history.

Nodes tagged page leave this file and open index.html, which owns the identity and portal journeys. The console cannot show those screens itself.
