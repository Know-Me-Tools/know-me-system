How to use this

Every node links to the exact state it describes. States that normally require a trigger — a wrong password, an expired token, an empty table — have their own routes here, so you never have to reproduce the condition by hand.

Once you leave the map, a Flow map control stays pinned at the bottom-left of every screen so you can step back without using browser history.

Nodes marked with a dashed outline are not built. They are listed because the journey implies them, so gaps stay visible rather than reading as complete.
