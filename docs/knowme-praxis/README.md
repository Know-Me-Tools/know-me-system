## Reproduce the published package

Use Python 3.11 or newer and a local checkout of [htmx-doc-forge](https://github.com/Prometheus-AGS/htmx-doc-forge) at commit `42336a3eee61261ab3b3cd896fa41dfd9bc23aa7`. Its existing Python dependencies must be installed. No new dependency is added to the KnowMe application.

```sh
python3 docs/knowme-praxis/build.py --forge-root /path/to/htmx-doc-forge
```

The command writes ignored `dist/` outputs and verifies all rebuilt files against the publication receipt. It uses the audited icons already present in the approved package, so assembly requires neither a browser nor network access. `source/body.json` is the frozen full-depth chapter assembly source; changing prose requires updating its corresponding chapter before rebuilding. Coverage records and source details remain linked to their revised owning chapters.
