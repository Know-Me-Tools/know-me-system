S14-005 · M1 — Hands become real (§06)

Governing revision: IM-01–04 · source requirement, not release evidence.

M1 — Hands become real (§06)

Wire knowme_hands::HandDefinition into the UAR scheduler in gen_ui_agent; enforce Cedar per skill invocation (deny-by-default, first-use consent); persist HandRun + audit log to SurrealDB; expose Tauri commands; connect the existing desktop/src/features/hands UI; 3-step wizard per UX-MOOD Screen 04.

Governing revision: IM-01–04 · source requirement, not release evidence.

M2 — OFP peer sync (§07)

QUIC transport + gossip rounds in knowme_ofp; entity envelopes over gen_ui_types::sync; CRDT merge into gen_ui_db_graph; did:key: payload encryption + mutual TLS; Settings → Instances/Sync panels (UX-MOOD 05–06) driven by PeerInstance / GossipRoundSummary. Conservative defaults are already encoded in SyncEntityKind::default_enabled().

S14-007 · M3 — Plugin host (§08)

Governing revision: IM-01–04 · source requirement, not release evidence.

M3 — Plugin host (§08)

wasmtime::component::bindgen!() against knowme-plugin.wit; sandbox limits (64 MiB / 30 s epoch) from SandboxLimits; IPFS fetch with gateway fallback + SHA-256 verify; Ed25519 manifest verification; installer dialog (UX-MOOD 07); build plugins/examples/hello-knowme end-to-end as the acceptance test.
